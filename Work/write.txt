5.1字典
python 对象系统很大程度上基于字典实现
字典是一组已命名的集合

---
x = 42
def bar():
    ...

def spam():
    ...
{
    'x' : 42,
    'bar' : <function bar>,
    'spam' : <function spam>
}
---
对象系统基本上就是在字典之上添加的一个额外层

字典保存实例数据__dict__
s = Stock('GOOG', 100, 490.1)
s.__dict__
{'name' : 'GOOG', 'shares' : 100, 'price': 490.1 }

每个实例都有自己的私有字典：
s = Stock('GOOG', 100, 490.1)     # {'name' : 'GOOG','shares' : 100, 'price': 490.1 }
t = Stock('AAPL', 50, 123.45)     # {'name' : 'AAPL','shares' : 50, 'price': 123.45 }

属性访问
在处理对象时，您可以使用.运算符访问数据和方法。

x = obj.name          # Getting
obj.name = value      # Setting
del obj.name          # Deleting
这些操作与底层运行的字典直接相关。

修改实例
修改对象的操作会更新底层字典。
s = Stock('GOOG', 100, 490.1)
s.__dict__
{ 'name':'GOOG', 'shares': 100, 'price': 490.1 }
s.shares = 50       # Setting
s.date = '6/7/2007' # Setting
s.__dict__
{ 'name': 'GOOG', 'shares': 50, 'price': 490.1, 'date': '6/7/2007' }
del s.shares        # Deleting
s.__dict__
{ 'name': 'GOOG', 'price': 490.1, 'date': '6/7/2007' }

6.2 自定义迭代
yield和return

yield 和for结合，'边走变算，用时再拿'，不占用内存，可以按需使用
def filematch(filename, substr):
    with open(filename, 'r') as f:
        for line in f:
            if substr in line:
                yield line  # 查到一行，立刻“交货”并暂停

return需要一次性交付，内存爆炸，且只能干等
def get_all_lines(filename):
    lines = []
    with open(filename, 'r') as f:
        for line in f:
            if 'IBM' in line:
                lines.append(line)
    return lines  # 一次性把所有的结果打包返回

7.1 可变参数  ：*args和**kwargs                           eg：7-1.py
*args:接受任意数量参数的函数称为使用可变参数的函数
def f(x, *args):
    pass
f(1,2,3,4,5)
def f(x, *args):
    # x -> 1
    # args -> (2,3,4,5)
eg:
元组可以展开为可变参数。
numbers = (2,3,4)
f(1, *numbers)      # Same as f(1,2,3,4)

**kwargs:函数可以接受任意数量的关键字参数
def f(x, y, **kwargs):
    ...
f(2, 3, flag=True, mode='fast', header='debug')
def f(x, y, **kwargs):
    # x -> 2
    # y -> 3
    # kwargs -> { 'flag': True, 'mode': 'fast', 'header': 'debug' }
eg:
字典也可以扩展为关键字参数
options = {
    'color' : 'red',
    'delimiter' : ',',
    'width' : 400
}
f(data, **options)
# Same as f(data, color='red', delimiter=',', width=400)
